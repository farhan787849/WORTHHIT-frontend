# WORTHHIT Frontend

Static shopping frontend for the WORTHHIT API.

## Backend
https://worthhit-api.onrender.com

## Files
- index.html — customer shopping site
- admin.html — basic admin dashboard
- app.js — API integration, cart, auth, COD, Razorpay
- style.css — responsive UI

## Deploy
This is a static site. It can be deployed on Render as a Static Site.
Publish directory: `.`
No build command is required.

## Admin
Open `/admin.html`.
Default credentials from the current backend:
Username: `admin`
Password: `ChangeMe123!`

Change the admin password in production before sharing the site.
